Política de Privacidade

Última atualização: setembro de 2026.

O Gerenciador de Estoque é um sistema de controle de estoque usado internamente por uma empresa e seus funcionários. Esta página explica quais dados o sistema guarda, para que servem e como uma pessoa pode pedir a correção ou remoção dos seus dados.

Quais dados o sistema guarda

  • Nome de usuário e senha - usados só para login. A senha nunca é guardada em texto puro: o sistema guarda um hash (uma transformação de mão única, que não pode ser revertida para descobrir a senha original).
  • Qual movimentação de estoque cada pessoa registrou - o sistema guarda qual usuário registrou cada entrada/saída de produto, com data e hora. Isso existe para dar rastreabilidade ao histórico de estoque (ex.: identificar quando e por quem uma quantidade foi retirada), não para monitorar o desempenho de ninguém.
  • Dados dos produtos cadastrados (nome, categoria, preço, quantidade) - são dados do negócio, não dados pessoais.

O sistema não pede nem guarda e-mail, telefone, CPF, endereço ou qualquer outro dado pessoal além do nome de usuário escolhido no cadastro.

Quem tem acesso

Cada empresa só enxerga os próprios dados - funcionários de uma empresa nunca têm acesso a produtos, movimentações ou funcionários de outra empresa cadastrada no sistema. Dentro de uma mesma empresa, cadastrar e gerenciar o acesso de funcionários é uma ação restrita ao papel de Gestor.

Onde os dados ficam guardados

O banco de dados roda num provedor de nuvem (Neon/PostgreSQL), com conexão sempre criptografada (HTTPS/TLS) entre o sistema e o banco.

Por quanto tempo os dados ficam guardados

Enquanto a conta e a empresa continuarem usando o sistema. Um produto "inativado" não é apagado do banco - o histórico de movimentações precisa continuar existindo para fins de auditoria e conferência de estoque.

Seus direitos

Você pode pedir a correção do seu nome de usuário ou a remoção da sua conta a qualquer momento, falando com o Gestor responsável pela sua empresa dentro do sistema.
